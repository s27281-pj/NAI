Educational Project Disclaimer

This website is an educational project designed to demonstrate the ethical risks and "dark patterns" associated with AI development.

Goal: This application aims to force the user to watch an advertisement by using real-time gaze tracking.

Artistic Reference: The project uses a clip from 'A Clockwork Orange' (1971) as a symbolic reference to the Ludovico Technique, highlighting the dystopian nature of forced digital consumption.

Privacy Note: To function, this app requires webcam access. This demo does not save your image, but be aware that such technology can be used for invasive surveillance.
